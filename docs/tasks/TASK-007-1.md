## 개요
- **목표**: (1) 투자원금 데이터를 시트 C열(계좌명 행) 기준으로 변경, (2) 2026-07-21 스냅샷 원금값 보정, (3) 대시보드 "전체 계좌 자산 비중"을 자산군(반도체/채권/미국배당/한국배당/금/현금) 기준으로 교체
- **관련 기능**: Google Sheets 수집 파이프라인, 대시보드 화면
- **요청 출처**: `01.요구사항/변경요청사항.txt`
- **참조 문서**: `docs/ROADMAP.md`(Phase 4), `docs/tasks/TASK-006.md`, `docs/tasks/TASK-007.md`

## 사전 조사 결과 (계획 단계에서 확인한 사실)

- `src/lib/google-sheets/parser.ts`의 `COLUMN.PRINCIPAL_AMOUNT=10`(J열)은 "합 계" 행의 구매금액 합을 투자원금으로 써왔음
- 실측(dry-run) 결과, "1.투자 현황(현재)" 탭 헤더가 `구분/투자원금/국가/코드/항목/자산구분/총 수량/구매단가/투자 비중/구매금액/현재가/조회금액/수익금액/수익율(%)` 순이며, **C열(인덱스2)이 "투자원금"**이고 이 값은 계좌명 행(첫 종목 행, `"퇴직연금\n(220-91-xxxx-757)"` 형태)에만 존재
- C열 값은 매수/매도가 없으면 거의 불변(사용자 확인)이므로, 오늘(2026-07-22) dry-run으로 읽은 값을 2026-07-21 스냅샷 보정에 그대로 사용 가능
- "4.계좌별 비중" 탭은 `[전체 계좌 비중]`(4행 헤더, 5~10행 자산군별 데이터, 11행 합계) 섹션을 포함하며, 시트 자체가 "1.투자 현황(현재) G열(자산구분)+M열(조회금액)" 기준으로 자동 동기화되는 수식 결과물
- 현재 대시보드 "전체 계좌 자산 비중" 도넛(`AccountRatioDonut`)은 계좌명 기준으로 DB `currentAmount`를 집계 — 자산군 기준이 아님
- 기존 아키텍처는 "수집은 cron, 조회는 DB"이므로, 자산군 비중도 DB에 저장 후 조회하는 방식으로 결정(사용자 확인, 시트 실시간 조회 방식은 배제)
